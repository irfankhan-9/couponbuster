# Implementation Plan: New League Dashboard & Dynamic Data Sync

## 1. Objective
Ensure that every league—whether the default mock league or a newly created one—renders an identical, high-fidelity UI. The "Make Your Picks" section, "Leaderboard," and "Financial Cards" must look perfect and reflect the specific configurations (fees, pot values, and deadlines) pushed from the Admin Panel.

## 2. Dynamic Routing & Data Binding
- **Component:** `pages/Dashboard.tsx`
- **Mechanism:** Utilize the `leagueId` from the URL to perform a 1:1 data lookup.
- **Implementation:**
    - The dashboard will fetch the specific `League` object from `MOCK_LEAGUES` based on the ID.
    - All labels (League Name, Weekly Fee, etc.) will bind to this object.
    - This ensures that if an Admin names a league "Swansea Sunday Syndicate," the user dashboard updates its title and branding automatically.

## 3. High-Fidelity "Make Your Picks" Section
- **Component:** `components/PickForm.tsx`
- **Dynamic Logic:**
    - The section will display "Week 1" for new leagues automatically by filtering `MOCK_WEEKS` for the corresponding `league_id`.
    - **Team Data:** The dropdowns will pull from the global `TEAMS` list, ensuring the user experience is identical to the "Valleys Premier League" demo.
    - **Deadlines:** The "Deadline In" countdown will be calculated dynamically using the `deadline_at` value set in the week data, which admins can eventually control.

## 4. Admin-Driven UI Updates
- **Pot Values:** The "Saved Pot" emerald card will pull directly from the `current_pot_pence` field. When an Admin overrides this value in the "Financial Settings" of the Admin Panel, the User Dashboard will update instantly upon refresh/navigation.
- **Membership Status:** The transition from the "Pending Request" screen to the active "Make Your Picks" dashboard is triggered solely by the Admin's "Approve" action in `Admin.tsx`. No additional code is required to "enable" a league; it is purely data-driven.

## 5. Visual Consistency & Branding
- **Layout Mirroring:** The grid system (2/3 for Picks, 1/3 for Leaderboard) will be strictly maintained across all leagues.
- **Empty States:** For brand-new leagues with no history, the Leaderboard will show the user with 0 points, maintaining the "Premium" look even before games begin.
- **Theme:** All leagues will inherit the "Emerald & Slate" professional palette, ensuring a consistent brand experience across the entire platform.

## 6. Verification Steps
1. **Create League:** Use Admin Panel to create "Test League" with a £50 fee.
2. **Push Changes:** Click "Push Changes" to sync the mock database.
3. **Join:** As a user, join "Test League."
4. **Approve:** As an Admin, approve the user.
5. **Dashboard Check:** Navigate to the new league dashboard and verify:
    - Title is "Test League."
    - "Saved Pot" reflects the initial value.
    - "Make Your Picks" is visible and functions exactly like the default league.
    - The navigation button "Back to Leagues" is present and animated.
