# Implementation Plan: Advanced Admin League Management

## 1. UI Redesign: League Creation
- **Action:** Remove "Create League" button from `pages/Leagues.tsx`.
- **Action:** Add "Create New League" section to the top of `pages/Admin.tsx`.
- **Fields:**
    - League Name (Mandatory).
    - Max Players (Integer).
    - Weekly Fee (£) - Total amount collected.
    - Pot Deduction (£) - Portion saved in the pot.
- **Constraint:** Once created, the League Name is locked (read-only in management view).
- **"Push Changes" Mechanism:** A visual action button that confirms the creation and "syncs" it to the public league list.

## 2. Admin Dashboard Structure (Drill-down)
- **Top Level:** A list of all leagues owned by the Admin.
- **Action:** "View League" button on each league card.
- **Drill-down View:** Clicking "View" opens a dedicated management interface for THAT specific league.
    - **Back Button:** Return to the global league list.
    - **Management Sections:**
        1. **Overview:** View stats (Users joined vs Max).
        2. **Member Management:** Approve/Reject requests for THIS league only.
        3. **Leaderboard Control:** Add/Subtract points for members of THIS league.
        4. **Financial Settings:** Edit Stake/Pot values (but not the name).

## 3. Joining Logic Enforcement
- **Constraint:** If `league.max_players` is reached (count of approved members), the "Join League" button in `pages/Leagues.tsx` should be disabled or replaced with "League Full".
- **Visual Feedback:** Show "Capacity: 18/20" on the league cards.

## 4. Technical Implementation
- **State Management:** Use local React state in `Admin.tsx` to handle the "Drill-down" view (switching between `ListView` and `ManageLeagueView`).
- **Data Persistence:** Update the `MOCK_LEAGUES` and `MOCK_MEMBERS` arrays in memory.
- **Filtering:** Ensure the Admin's view of "Join Requests" and "Points Management" is filtered by the `activeLeagueId` being managed.

## 5. Visual Consistency
- Maintain the Emerald/Gold/Slate color palette.
- Use clear iconography for "Push Changes" (Cloud/Sync icons).
- Use distinct styling for "Locked" fields (grayed out background).
