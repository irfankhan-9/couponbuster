# Implementation Plan: League Deadline Synchronization & Weekly Cycle

## 1. Objective
Ensure the League Dashboard deadline timer is 100% synchronized with the Admin Panel settings and enforce a strict weekly cycle: **Open on Monday (00:00) -> Close at Deadline (Default: Friday 23:00) -> Remain Closed until next Monday.**

## 2. New Logic: The Scheduler Utility
Create a centralized logic file `utils/scheduler.ts` to determine the current state of a league based on "real-time" calculation rather than static database strings.

**Logic Definition:**
1.  **Cycle Start:** The "Game Week" begins every **Monday at 00:00**.
2.  **Cycle End:** The "Game Week" pick window closes at the configured `pick_deadline_day` and `pick_deadline_hour`.
3.  **Blackout Period:** From the Deadline until the following Monday at 00:00, the market is **Closed**.

**Function: `calculateLeagueWindow(league)`**
- **Inputs:** `league.pick_deadline_day` (0-6), `league.pick_deadline_hour` (0-23).
- **Calculation:**
  - Get `currentDate`.
  - If `currentDate` is Sunday (Day 0): **Status = CLOSED** (Waiting for Monday).
  - Determine `thisWeeksDeadline`:
    - Calculate the date of the deadline day for the *current* week (relative to the most recent Monday).
  - Compare `currentDate` vs `thisWeeksDeadline`:
    - If `currentDate` < `thisWeeksDeadline`: **Status = OPEN**.
    - If `currentDate` >= `thisWeeksDeadline`: **Status = CLOSED**.
- **Output:** `{ isOpen: boolean, deadlineDate: Date }`.

## 3. Component Updates

### A. Dashboard (`pages/Dashboard.tsx`)
- **Import:** The new `calculateLeagueWindow` utility.
- **Logic:**
  - Retrieve `activeLeague`.
  - Call `calculateLeagueWindow(activeLeague)` to get the *real* status and deadline.
- **UI States:**
  - **If Open:**
    - Inject the calculated `deadlineDate` into the `activeWeek` object (overriding the mock data).
    - Render the `<PickForm>` as normal.
  - **If Closed:**
    - **Do NOT** render the `<PickForm>`.
    - Instead, render a high-fidelity "Market Closed" card (similar to the "Schedule Awaiting Approval" card) with a message: "The pick window is closed for the weekend. Market re-opens Monday."

### B. Admin Panel (`pages/Admin.tsx`)
- **Creation Default:** Ensure `handleCreateLeague` initializes `pick_deadline_day: 5` (Friday) and `pick_deadline_hour: 23` (11 PM).
- **Syncing:** No complex data-push logic is needed for deadlines anymore. Since the Dashboard now calculates the deadline *live* based on the League Settings (Day/Hour), changing the setting in Admin immediately updates the user view without needing to rewrite static mock week dates.

### C. Constants (`constants.ts`)
- **Verification:** Ensure `MOCK_LEAGUES` seed data defaults to Day 5 / Hour 23 to demonstrate the feature correctly out of the box.

## 4. Verification
- **Scenario 1 (Mid-week):** If today is Wednesday, and deadline is Friday -> Dashboard shows "Open", Countdown matches Friday 11PM.
- **Scenario 2 (Admin Change):** Change deadline to Tuesday (Yesterday) in Admin. -> Dashboard immediately switches to "Market Closed".
- **Scenario 3 (Weekend):** If today is Saturday -> Dashboard shows "Market Closed".
