# Implementation Plan: Syndicate Logic V2 - "Fair Play" & Automation

## 1. "First In, First Pick" (Week 1 Logic)
**Objective:** The pick order for the inaugural week must be strictly determined by the chronological order in which users joined (and were approved for) the league.

**Mechanism:**
- **Join Timestamp:** We rely on `joined_at` in the `LeagueMember` record.
- **Dynamic Order Building:** 
  - When an Admin approves a user in `Admin.tsx`, the system locates "Week 1" for that league.
  - The system recalculates the `pick_order` for Week 1 by sorting ALL approved members by their `joined_at` date.
  - This ensures that even if User B is approved before User A, if User A *requested* to join first, User A gets Pick #1.

## 2. The Linear Draft & "Half-Time" Reset
**Objective:** A strict sequence where the order resets completely between Round 1 (Banker) and Round 2 (Cover). Snake drafting (1-2-3-3-2-1) is NOT used.

**Mechanism:**
- **Round 1:** Order [A, B, C].
- **Transition:** When C finishes Round 1:
  - System detects `isLastInOrder`.
  - System updates `draft_round` to `2`.
  - System resets `current_turn_user_id` to `A` (Index 0).
- **Round 2:** Order [A, B, C].
- **Completion:** When C finishes Round 2, the week is marked `completed`.

## 3. The "Red Light" User Interface
**Objective:** Clear blocking for users who are out of turn.

**UI Updates (`DraftRoom.tsx`):**
- **Active Picker:** Sees the selection form.
- **On Deck / Waiting:** 
  - Displays a large, clear "Waiting for [Name]" card.
  - Status Badge: "Round 1: Pick 2 of 5".
  - Polling: The component auto-refreshes (simulated) to check if the turn has passed.

## 4. Automated Weekly Rotation
**Objective:** Week 2 automatically rotates the order so the previous #1 becomes last.

**Mechanism (`Admin.tsx` Week Generation):**
- When the Admin generates "Week 2" (or when the scheduler opens it):
- **Input:** Week 1 Order `[A, B, C]`.
- **Function:** `rotateWeeklyOrder`.
- **Output:** Week 2 Order `[B, C, A]`.
- This calculation happens once at the moment of week creation/opening.
