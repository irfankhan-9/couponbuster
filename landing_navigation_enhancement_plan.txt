# Implementation Plan: Landing Page Navigation & Interaction Polish

## 1. Objective
Ensure every clickable element on the Landing Page (`pages/Landing.tsx`) performs a specific, functional action. Replace the default "instant jump" navigation with a physics-based, premium smooth-scroll animation that feels high-end ("unnoticeable but beautiful").

## 2. The "Premium Scroll" Mechanism
Instead of relying solely on the browser's default scroll behavior (which can be jerky or inconsistent across devices), we will enforce a consistent visual experience.

- **Global CSS:** Apply `html { scroll-behavior: smooth; }` in the global styles. This is the most robust, performance-friendly way to handle anchor links without complex JavaScript libraries that might break in production.
- **Scroll Padding:** Add `scroll-padding-top: 5rem;` (approx 80px) to the `html` tag. This ensures that when a user clicks "How It Works," the section header doesn't get hidden behind the sticky navigation bar. It lands perfectly framed.

## 3. Button & Link Audit (Fixing Broken Interactions)

### A. Navigation Bar
- **Current State:** `<a href="#section">` tags exist.
- **Action:** Verify strict ID matching with target sections.
- **Refinement:** Ensure the "Login" and "Start a League" buttons point explicitly to `/leagues` (the app entry point).

### B. Hero Section (Critical Fixes)
- **"Create Your League" Button:** Ensure it links to `/leagues`.
- **"See How It Works" Button:** 
    - **Current Status:** It is a generic `<button>` with no action.
    - **Fix:** Convert to an `<a>` tag pointing to `#how-it-works`.
    - **Animation:** Will inherit the global smooth scroll.

### C. Footer Links
- **Current Status:** Placeholder `#` links.
- **Fix:** 
    - "Features" -> Link to `#benefits`.
    - "Pricing" -> Link to `#pricing`.
    - "Support" -> Link to `#faq`.
    - Legal links can remain as placeholders or point to a dedicated (future) page, but for now, we will ensure they don't cause page jumps (use `e.preventDefault()`).

## 4. Visual Polish (Micro-Interactions)
To achieve the "visually beautiful" requirement:
- **Hover States:** Enhance the "See How It Works" ghost button. Add a subtle background tint (`hover:bg-emerald-800/30`) and a text color shift to white to make it feel responsive.
- **Active States:** Ensure buttons have a `transform active:scale-95` property so they feel tactile when clicked.

## 5. Technical Implementation Steps

### Step 1: Global Style Update (`index.html`)
- Add the `scroll-behavior: smooth` and `scroll-padding-top` rules to the internal `<style>` block.

### Step 2: Component Refactor (`pages/Landing.tsx`)
- Update the Hero "See How It Works" button to be an anchor tag: `<a href="#how-it-works" ...>`.
- Update Footer links to point to relevant sections on the page where applicable.
- Verify section IDs (`id="how-it-works"`, `id="benefits"`, etc.) match exactly.

## 6. Verification Checklist
1.  **Scroll Test:** Click "How It Works" from the top nav.
    - *Success:* The page glides down smoothly and stops with the "How It Works" header clearly visible below the sticky nav.
2.  **Hero Button Test:** Click "See How It Works".
    - *Success:* Same smooth glide to the numbered steps section.
3.  **App Entry Test:** Click "Start a League".
    - *Success:* Immediate navigation to the `/leagues` page.
4.  **Mobile Test:** Verify the smooth scroll works on touch devices via the mobile menu.
