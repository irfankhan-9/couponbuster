# Implementation Plan: Navigation Cleanup & Role-Based Access

## 1. Objective
Declutter the global application header by removing the explicit "Leagues" and "Admin" text buttons from the top navigation bar. This creates a cleaner, more focused user interface while ensuring administrative features remain accessible to authorized users via a discreet, secure location.

## 2. Targeted Component
- **File:** `components/Layout.tsx`
- **Context:** The main `<nav>` block handling desktop and mobile menus.

## 3. Structural Changes

### A. Desktop Navigation (Top Bar)
1.  **Remove:** Delete the entire `div` container responsible for the "Desktop Menu" (previously containing `Link to="/leagues"` and `Link to="/admin"`).
2.  **Result:** The top bar will strictly feature the "Coupon Busters" Brand/Logo on the left and the "Profile Trigger" on the right.

### B. Mobile Navigation (Drawer)
1.  **Remove:** Delete the `Link` elements for "Leagues" and "Admin Console" from the mobile menu drawer.
2.  **Refinement:** Keep the drawer functionality for the "Profile" details and "Logout" button, ensuring mobile users still have account control.

### C. Profile Dropdown (The New Command Center)
To satisfy the requirement of "do not break anything" while removing the top-bar Admin section, we must move the Admin access to the Profile Dropdown.

1.  **Logic Injection:** Inside the dropdown menu (the "Billion-Dollar Dropdown Card"), add a conditional check:
    ```typescript
    {currentUser?.role === UserRole.LEAGUE_ADMIN && (
       // Admin Link Item
    )}
    ```
2.  **UI Addition:** Add a menu item for "Admin Console".
    - **Icon:** `LayoutDashboard` or `Settings`.
    - **Style:** Consistent with the existing "Sign Out" button (clean row, hover state).
3.  **Enhancement (Optional):** Add a "My Leagues" link to the dropdown as well. This restores the functionality of the removed "Leagues" button in a cleaner list format, ensuring users never feel "stuck."

## 4. User Experience Logic
- **Standard User:** Sees only the Logo and their Profile. No "Admin" link is visible anywhere. Navigation to leagues is done via the Landing Page "Login" or clicking the Logo.
- **Admin User:** Sees a clean header. To access the Admin Panel, they click their Profile Avatar -> "Admin Console".
- **Navigation Safety:** Since the `Dashboard.tsx` and `Admin.tsx` pages already contain "Back" buttons (`ChevronLeft`), deep navigation remains fluid.

## 5. Verification
- **Visual:** The top center of the navbar is empty/clean.
- **Role Check:** Change `CURRENT_USER_ID` to `u2` (Standard User) in `constants.ts`. Verify "Admin Console" does not appear in the profile dropdown.
- **Access Check:** Change `CURRENT_USER_ID` back to `u1`. Verify "Admin Console" appears in the dropdown and successfully routes to `/admin`.
